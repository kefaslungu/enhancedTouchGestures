# Улучшенные Жесты Сенсорного Экрана

* Авторы: Joseph Lee, Kefas Lungu

Это дополнение предоставляет дополнительные жесты для сенсорного экрана NVDA, включая жесты для объявления фокуса и настроек кольца синтезатора.

Примечание: для работы этого дополнения требуется NVDA 2026.2 или выше, установленная на компьютере с сенсорным экраном под управлением Windows 10 или 11.

## Команды

### Доступные везде

* Тройное нажатие двумя пальцами: выходит из NVDA!
* Движение тремя пальцами вправо: нажать клавишу Tab.
* Движение тремя пальцами влево: нажать Shift+Tab.
* Движение тремя пальцами вниз (объектный режим): прочитать текущее окно.
* Двойное касание тремя пальцами: переключает уровни речевых символов, определяющие, какие символы произносятся.
* Тройное нажатие тремя пальцами: переключает затемнение экрана.
* Касание четырьмя пальцами: переключает режимы приглушения звука.
* Двойное касание четырьмя пальцами: переключение режима справки по вводу.
* Смахивание четырьмя пальцами влево: сообщить об объекте, находящемся в фокусе.
* Смахивание четырьмя пальцами вправо: объявить текущий объект навигатора.
* Смахивание четырьмя пальцами вверх: объявить заголовок текущего окна.
* Смахивание четырьмя пальцами вниз: отобразить текст в строке состояния.

## Сенсорный режим настроек синтезатора

Вы можете использовать этот режим для быстрого изменения настроек синтезатора, таких как выбор голоса и изменения громкости. В этом режиме используются пролистывания двумя пальцами влево или вправо, чтобы перемещаться между настройками синтезатора и пролистывания двумя пальцами вверх и вниз, чтобы изменить значения. Это зеркало жестов настроек клавиатурных команд кольца синтезатора.

Список изменений, вносимых между каждыми выпусками дополнения, смотрите в документе [список изменений для выпусков дополнения][1].
